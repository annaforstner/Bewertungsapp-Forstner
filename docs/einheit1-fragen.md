# Einheit 1 - Fragen

## Was ist der Unterschied zwischen Capacitor und Cordova?
**Capacitor** und **Cordova** sind beides Open Source Programme, um Apps mit HTML, CSS und Javascript zu programmieren. Capacitor gilt als Nachfolger von Cordova. Es wurde vom Ionic Team entwickelt und unterscheidet sich vor allem im Umgang mit den Projekten.


## Was macht ein ORM wie Sequelize, und wofür braucht man zusätzlich die sequelize-cli?
**ORM** steht für Object Relational Mapping und übersetzt die Daten einer Datenbank in Javascript. Anstatt SQL- Befehle kann man das Programm mittels Javascript bedienen.
(Man muss dafür die Objekte und Klassen verwenden).
Die **Sequelize-cli** hilft dabei datenbankbezogene Aufgaben über das Terminal zu automatisieren und zu verwalten.


## Was unterscheidet npm install von npx beim Ausführen eines Pakets?
**npm install** installiert die Pakete und fügt sie dem Programm hinzu während **npx** die Pakete benutzt, ohne sie dauerhaft installieren zu müssen (Sie können aber temporär installiert werden).


## Was ist REST, und warum passt das Konzept zu einer Client-Server-Architektur wie Ionic-App und Node-Backend?
**REST** steht für Representational State Transfer und komuniziert zwischen Client und Server. Er nutzt GET, POST, PUT und DELETE. Es passt dazu, weil es als selbständiges Bindeglied zwische Client (Ionos) und Server (Node) dient.
